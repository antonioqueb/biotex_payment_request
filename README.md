# Biotex - Solicitud de pago y CxP

Módulo para **Odoo 19 Enterprise** · Alphaqueb Consulting SAS · Proyecto Biotex (fase 1).

Solicitud de pago generada desde la OC, cola para administración, comprobante, estado visible para compras; CxP consolidadas por razón social y proveedor

## Dependencias
`biotex_purchase_request`, `account`

## Instalación
1. Clonar dentro del `addons_path` del servidor Odoo 19 junto con los demás módulos `biotex_*`.
2. Actualizar lista de aplicaciones e instalar `biotex_payment_request`.
